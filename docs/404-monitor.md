# 404 Monitor

Optional lightweight 404 logging. **Disabled by default.**

## Privacy

- No IP addresses
- No personal data
- Query strings with sensitive parameters ignored
- System paths (`/wp-*`, feeds) skipped

## Storage

Aggregated by normalized path: hit count, last seen, referrer domain/path.

## Actions

- Create Redirect
- Ignore
- Mark Resolved

Enable under **Settings → Redirects & 404**.
