# Template Overrides

Themes may override RevIt Publisher public templates:

```
your-theme/revit-publisher/vehicle-hub.php
your-theme/revit-publisher/vehicles-index.php
your-theme/revit-publisher/manufacturer-hub.php
```

Plugin fallbacks:

```
revit-publisher/templates/vehicle-hub.php
revit-publisher/templates/vehicles-index.php
revit-publisher/templates/manufacturer-hub.php
```

RevIt components use scoped CSS classes (`revit-publisher-*`) and do not override global theme typography or colors.
