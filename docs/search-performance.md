# Search Performance

**RevIt Publisher → Search Performance** shows Google Search Console metrics for RevIt content.

## Overview

28-day summary with comparison to previous period:

- Clicks
- Impressions
- CTR
- Average position (lower number = improvement)

## Filters

Pages tab supports filtering by vehicle and article type.

## Data source

All metrics come from locally synced Search Console snapshots — not live API calls on page load.

See `docs/google-search-console.md` for API limitations.
