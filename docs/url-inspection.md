# URL Inspection

Operator-triggered URL inspection via Search Console API.

## Usage

From article editor or Search Performance → Indexing:

**Inspect in Google**

## Quota

Daily inspection limit is configurable (default 20). Results are cached locally.

## Displayed fields

Only fields returned by the API:

- Indexed status
- Last crawl time
- Google canonical
- User canonical
- Coverage state

No invented index details.
